# 数据集



## QVHighlights 数据集

> [QVHighlights 数据集](https://github.com/jayleicn/moment_detr/tree/main/data)

数据集标注文件划分为**训练集、验证集、测试集**三个子集，文件均采用**JSON Lines**格式存储，在 Python 中可将文件每一行单独读取为一个字典对象。

```json
{
    "qid": 8737, 
    "query": "A family is playing basketball together on a green court outside.", 
    "duration": 126, 
    "vid": "bP5KfdFJzC4_660.0_810.0", 
    "relevant_windows": [[0, 16]],
    "relevant_clip_ids": [0, 1, 2, 3, 4, 5, 6, 7], 
    "saliency_scores": [[4, 1, 1], [4, 1, 1], [4, 2, 1], [4, 3, 2], [4, 3, 2], [4, 3, 3], [4, 3, 3], [4, 3, 2]]
}
```



**qid:** 查询语句的唯一编号

**query**：文本查询语句（自然语言描述视频目标片段内容）

**duration**：截取视频片段的总时长（单位：秒，整数）

**vid**：视频唯一标识

命名规则：`油管视频ID_截取起始秒数_截取结束秒数`

视频访问拼接链接：

```
https://www.youtube.com/embed/油管ID?start=起始时间&end=结束时间&version=3
```

示例对应链接：

```
https://www.youtube.com/embed/bP5KfdFJzC4?start=660&end=810&version=3
```

**relevant_windows**：**目标关键时间区间**

二维列表，每组`[起始时间, 结束时间]`代表视频中符合文本描述的目标片段时间范围

**relevant_clip_ids**：**有效片段编号**

视频预先切分为**2 秒一帧**的短视频块，该列表存储落在目标时间区间内的片段序号，序号从 0 开始排序

**saliency_scores**：显著性人工打分

子列表与`relevant_clip_ids`片段一一对应，每个子列表包含**3 位标注员**的打分结果

打分标准：**4 分 = 最优**，**0 分 = 最差**
